# Lab materials

Data sets and files used in the hands-on labs, **one folder per lab**. See
[CONTRIBUTING.md](../CONTRIBUTING.md) for how to add or name files.

_(These originally lived at `github.com/molevolworkshop/assets/data`, but the 1 GB GitHub
Pages limit made that unwieldy for large data sets, so they moved here.)_

| Lab | Folder | Contributed by |
|---|---|---|
| IQ-TREE | `iqtree_lab/` | Minh Bui |
| Model selection (PAUP*) | `modsel_sim_tutorial/` | David Swofford |
| PhyloNetworks (MrBayes data) | `mrbayes/` | Claudia Solís-Lemus |
| Multiple sequence alignment | `msa_lab/` | George Tiley |
| PAML | `paml_lab/` | Joe Bielawski |
| RevBayes | `revbayes/` | see note below |
| Migrate | `migrate_tutorial/` | Peter Beerli |
| SVDQuartets | `svdquartets_tutorial/` | Laura Kubatko & David Swofford |

**RevBayes:** `revbayes/genetree/` holds files for the
[Nucleotide substitution models](https://revbayes.github.io/tutorials/ctmc/) tutorial
(Sebastian Höhna, Michael Landis, Brian Moore, Tracy Heath). `revbayes/divtime/` holds files
for the [time-calibrated phylogeny of fossil and extant taxa](https://revbayes.github.io/tutorials/fbd_simple/)
tutorial (Joëlle Barido-Sottani, Joshua Justison, April M. Wright, Rachel C. M. Warnock,
Walker Pett, Tracy A. Heath).
